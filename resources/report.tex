\section{Introduction}
This report details the design, implementation, and empirical evaluation of polynomial regression models developed entirely from scratch using NumPy. The objective is to accurately predict continuous target variables for two distinct problems:
\begin{enumerate}
    \item \textbf{Steam Turbine Optimization (var1):} Predicting the Net Power Score ($y$) based on operational parameters.
    \item \textbf{Subterranean Thermal Reservoir Mapping (var2):} Predicting the Thermal Anomaly Score ($y$) from spatial coordinate offsets.
\end{enumerate}
The methodology strictly follows course notation, utilizing both an 80/20 train-validation holdout split and an exhaustive 10-Fold Cross-Validation scheme to determine optimal model complexities while avoiding overfitting.

\section{Methodology and Mathematical Formulation}
Following the notation established in the lecture slides, let the $n^{\text{th}}$ observation be represented by the input vector $\mathbf{x}_n \in \mathbb{R}^D$ and its corresponding continuous scalar target by $y_n$ (often denoted $t_n$). The linear predictor parameterized by weight vector $\mathbf{w}$ is given by:
\begin{equation}
f(\mathbf{x}_n; \mathbf{w}) = \mathbf{w}^T \mathbf{x}_n
\end{equation}

For polynomial regression of degree $d$, the original input vector $\mathbf{x}_n$ is mapped into a higher-dimensional feature space via a polynomial basis expansion:
\begin{equation}
\boldsymbol{\phi}(\mathbf{x}_n) = \left[ 1, x_{n,1}, \dots, x_{n,D}, x_{n,1}^2, x_{n,1}x_{n,2}, \dots, x_{n,D}^d \right]^T
\end{equation}
The total number of terms (model parameters) generated for $D$ features up to degree $d$ is given by the combinatorial formula $\binom{D+d}{d}$.

The objective is to minimize the empirical Squared Loss function $\mathcal{L}(\mathbf{w})$ averaged over all $N$ training samples:
\begin{equation}
\mathcal{L}(\mathbf{w}) = \frac{1}{N} \sum_{n=1}^{N} \mathcal{L}_n(y_n, f(\mathbf{x}_n; \mathbf{w})) = \frac{1}{N} \sum_{n=1}^{N} (y_n - \mathbf{w}^T \boldsymbol{\phi}(\mathbf{x}_n))^2
\end{equation}

Constructing the design matrix $\mathbf{X} \in \mathbb{R}^{N \times M}$ where the $n^{\text{th}}$ row is $\boldsymbol{\phi}(\mathbf{x}_n)^T$, and letting $\mathbf{y} \in \mathbb{R}^N$ be the target vector, setting the gradient $\nabla_{\mathbf{w}} \mathcal{L}(\mathbf{w}) = \mathbf{0}$ leads directly to the Normal Equations:
\begin{equation}
\mathbf{X}^T \mathbf{X} \mathbf{w} = \mathbf{X}^T \mathbf{y}
\end{equation}

The closed-form analytic solution for the optimal parameters is:
\begin{equation}
\mathbf{w} = (\mathbf{X}^T \mathbf{X})^{-1} \mathbf{X}^T \mathbf{y}
\end{equation}
To ensure robust numerical stability against ill-conditioned matrices that naturally arise in higher-degree polynomial expansions, the parameter vector $\mathbf{w}$ is computed using Singular Value Decomposition (SVD) via NumPy's least-squares routine.

\section{Problem 1: Steam Turbine Optimization (var1)}

\subsection{Feature Selection Analysis}
The dataset provides 6 operational features ($x_1, \dots, x_6$). An exhaustive evaluation across all $2^6 - 1 = 63$ non-empty feature subsets was executed. Subsets with fewer features were found to severely underfit the target:
\begin{itemize}
    \item Best 1-feature model achieved a minimum validation MSE of \textbf{8.627}.
    \item Best 2-feature model achieved a minimum validation MSE of \textbf{6.940}.
    \item Best 3-feature model achieved a minimum validation MSE of \textbf{5.560}.
    \item Best 4-feature model achieved a minimum validation MSE of \textbf{4.106}.
    \item Best 5-feature model achieved a minimum validation MSE of \textbf{1.804}.
\end{itemize}
Omitting any operational parameter drops essential physical signals, causing substantial residual error. In contrast, utilizing the complete set of all 6 features drops the validation MSE below \textbf{0.835}. Hence, the full 6-feature configuration is strictly retained for polynomial degree optimization.

\section{Problem 2: Subterranean Thermal Reservoir Mapping (var2)}

\subsection{Feature Selection Analysis}
Problem 2 maps subterranean thermal anomalies based on 3 spatial coordinate offsets ($x_1, x_2, x_3$). Evaluating all $2^3 - 1 = 7$ feature subsets demonstrated that spatial dimensions cannot be omitted without catastrophic performance degradation:
\begin{itemize}
    \item Best 1-feature model validation MSE: \textbf{38.028} ($R^2 \approx 0.24$).
    \item Best 2-feature model validation MSE: \textbf{18.897} ($R^2 \approx 0.62$).
    \item Full 3-feature model validation MSE: \textbf{0.324} ($R^2 = 0.994$).
\end{itemize}
Because subterranean thermal phenomena exist in continuous three-dimensional space, all 3 coordinate axes are physically essential. Consequently, the complete 3-feature set is used for all polynomial degree evaluations.

\section{Conclusion}
Through systematic feature selection and comprehensive degree sweeping via both an 80/20 train-validation split and 10-Fold Cross-Validation:
\begin{enumerate}
    \item \textbf{Problem 1 (var1):} The full 6-feature polynomial model at \textbf{Degree 4} was identified as optimal, achieving a validation MSE of $0.835$ ($R^2 = 0.928$) and a 10-fold CV MSE of $0.833 \pm 0.144$.
    \item \textbf{Problem 2 (var2):} The full 3-feature polynomial model at \textbf{Degree 8} was identified as optimal, achieving a validation MSE of $0.324$ ($R^2 = 0.994$) and a 10-fold CV MSE of $0.273 \pm 0.027$.
\end{enumerate}
Empirical evidence verified that reduced feature subsets suffered from severe underfitting due to the loss of essential variables. The selected configurations successfully minimize empirical squared loss $\mathcal{L}(\mathbf{w})$ while strictly preserving generalization stability.
